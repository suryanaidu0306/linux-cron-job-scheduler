# Linux Cron Job Scheduler

## 📌 Description

This project demonstrates how to automate tasks in Linux using
Bash scripting and Cron.

The project creates a Bash script that records the date, time,
and current user whenever the scheduled Cron job runs.

## 🛠️ Technologies Used

- Linux
- Bash Shell
- Cron
- Crontab

## 📂 Project Files

- `scheduled_task.sh` - Bash script executed by Cron
- `README.md` - Project documentation

## 🚀 How to Run

Give execution permission:

```bash
chmod +x scheduled_task.sh
